# Contributing to JEDI

Active development happens on `main`.

Historical branches are retained for reference only.

## Development

```bash
pnpm install
pnpm verify    # test + build + boundaries + app boundaries + metrics
```

## Sprint Discipline

Every PR must satisfy three pillars:

1. **Capability** — feature works
2. **Quality** — tests pass, fitness gate PASS
3. **Knowledge** — docs and Capability Matrix updated
